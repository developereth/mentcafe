📋 Quick Guide

1. Use Food Menu & Drinks Menu tabs to edit items
2. Each item has: Image URL | Name | Price (ETB)
3. Use Social Media tab to update your links
4. Use Promotions tab to change discount & hashtags
5. Click Save All to save changes to browser storage
6. Use Export to backup your menu as JSON file
7. After saving, refresh your website pages to see changes
